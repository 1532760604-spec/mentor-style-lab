# Mentor Style Lab

用经授权的英文论文建立可核查的作者文风画像，再指导新稿写作。第一版在当前对话中工作，不调用模型 API，不进行模型微调。

## 当前版本 v0.4

已实现：递归登记 PDF、文件哈希、原文逐页提取、页码与文本块坐标保留、完全重复检测、疑似同文不同版本分组、按论文组确定学习/开发/测试分区、基础质量清单、带出处的人工精选语料统计。尚未实现：OCR、可靠的自动章节识别、自动画像推断、生成模型、语义事实核验。

所有自动提取结果均为待审核语料，不会直接成为风格证据。合著文章只能支持“这些文章的共同文风”，不能直接证明目标作者个人习惯。

v0.3 新增完整摘要的论文级词面特征对照，输出目标组与参考组的命中计数和具体证据，见 `docs/contrast-workflow.md`。这用于发现候选差异，不是独立效果验证。

v0.4 补充作者角色、在线日期与终刊年份、同文版本和对照来源纠正的审核流程，见 `docs/source-selection.md`。本地章节画像推进到引言贡献、方法理由、结果解释和局限性；它们仍是待验证的候选模式。作者专用证据、规则与写作指令全部保存在忽略同步的 `local/`。

## 本地运行

需要 Python 3.11+，安装 `requirements.txt` 中的依赖。以下命令在项目目录运行：

```powershell
python stylelab.py ingest --source '你的PDF文件夹'
python -m unittest discover -s tests -v
python stylelab.py profile --excerpts local/curated/excerpts.jsonl
```

`ingest` 仅读取原文件；输出全部进入忽略同步的 `local/`。首次创建 `local/splits.json`，重跑沿用分区。新发现的重复版本若使历史分区发生冲突，立即报错，需人工审查后明确重建分区，禁止静默污染测试集。疑似重复通过文件名相似度分组，是保守候选，不是已确证结论。年份来自目录，只作导航，不作为已验证的发表年份。

查看 `local/reports/inventory.md` 和 `local/manifest.json`。`local/extracted/<paper_id>.json` 保留逐页文本、文本块坐标、来源哈希。页面阅读顺序、页眉页脚、公式、脚注、两栏混排尚未校验。

## 精选语料契约

从学习集取段落；对照 PDF 页面确认后，参照 `templates/excerpt.example.json` 写入 `local/curated/excerpts.jsonl`（每行一个 JSON 对象）。必须填写论文 ID、PDF 页序号（从 1 开始）、章节、段落全文及审核状态。程序核对段落确实存在于该页，拒绝开发集/测试集、未审核段落、重复段落以及未知论文。若 PDF 有断词，只允许统一空白与行末连字符；不能凭记忆修订后当作原文。

统计输出 `local/profiles/surface-style.json`。这些仅是词表/正则得到的表层描述，不是文风准确率，也不证明个人作者归属。深层论证习惯由 `prompts/analyze-style.md` 指导当前对话分析，每条规则需要出处和反例。

v0.2 新增精选文件夹登记、目标作者/领域参考角色区分和画像证据核验。用 `profile --selection ... --out ...` 为精选语料单独生成统计，不覆盖早期试验。完整流程见 `docs/selected-corpus-workflow.md`。新稿任务输入模板见 `templates/new-writing-task.md`。作者专用画像与写作指令保存在 `local/profiles/`，不随代码同步。

## 推荐 Git 工作方式

建议创建用户自己的 **私有 GitHub 仓库**。同步代码、模板、提示词、测试和变更记录；原 PDF 保持在现有文件夹。语料、抽取文本、作者画像、生成稿、盲评记录、路径与密钥默认放 `local/`，不推送。私有仓库仍不等于语料备份；原论文另行保留本地备份。

本地仓库可先迭代。用户创建空的私有远程仓库后，在确认暂存清单不含语料的情况下添加远程并推送。不强制推送、不覆盖远程历史。建议每个可验证阶段一个提交；实验使用单独分支，记录输入哈希、提示词版本与模型名称。当前无公开发布动作。

## 下一阶段

1. 人工抽检两栏、扫描、书籍/综述/实证论文与作者列表，处理重复版本候选。
2. 从学习集选 5–8 篇有代表性的文章，明确作者参与写作的程度；按章节精选段落。
3. 生成带逐页出处的初版画像，保留跨文章反例，不把研究主题当作风格。
4. 开发集调整画像；冻结后，仅一次查看测试集作最终评估。当前分区只是初始方案，不代表测试已完成。
5. 同一新内容要求下比较普通写作、给示例、画像+示例三种方法，由导师盲评。

研究来源与采用边界见 `docs/research-notes.md`。本项目独立编写，没有复制上游项目代码。
