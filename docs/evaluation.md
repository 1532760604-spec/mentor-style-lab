# 验证计划

## 软件验证

单元测试覆盖原文件不变、完全重复与疑似版本分组、分区冲突拒绝、开发/测试语料隔离、段落出处匹配。实际资料另核验源哈希、页数与抽取页数；抽取成功不等于阅读顺序正确。

## 文风验证

以整篇论文/版本组为分区单位。先审核同文不同版本候选、作者贡献、文章类型与年份分布，再冻结。初始哈希分区只是候选，不能替代人工审核。画像构建只用 learning；development 用于迭代；test 最后评价，若用来改画像则必须降级为 development。

同一组新内容任务生成三类输出：普通模型；仅同类段落示例；画像+同类段落示例。统一模型、事实材料与长度范围，随机编号。第一轮以 6–10 项任务试行，不能据此声称统计上可靠的成功率。

导师独立比较：像不像其写作方式、段落推进是否一致、措辞是否自然、学术内容是否完整。独立记录数字/引用/因果表述/否定改变，以及与语料的长片段重合。表层统计只辅助解释，不合成为“复刻百分比”。保留负结果。
