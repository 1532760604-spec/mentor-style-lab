# 作者角色、时间与作品版本审核

## 选择顺序

1. 先核验正文署名页，不能把 PDF 元数据中的 Author 字段当作作者表。
2. 区分独立署名、第一作者、通讯作者和其他合著；作者贡献声明若可得，单独记录写作角色。署名次序不证明个人执笔。
3. 独立署名学位论文与同期刊文分层，致谢中的修改协助和章节已发表合著版本要单独注明。历史论文不能冒充当代风格样本。
4. 同一角色层优先关注首次在线发表时间，并单独保留终刊年份、接收日期。文件夹年份、下载日期、文件修改时间只作导航。
5. 如未找到已核实的近期独作，报告范围和未确认项，使用明确标注的替代层；不能推断作者没有独作。

人工审核记录保存在 `local/`，包含论文 ID、来源哈希、署名核验页、作者角色、写作贡献是否确认、在线日期、终刊年份、DOI、用途分层和审核者。

## 同文版本

同 DOI、题名和署名的早期在线版与终刊版按一项作品计数；选择一份作为本轮原页引用来源，并记录另一版本。页码不能跨版本拼接。同 DOI 本身不是任意文本都相同的保证，应核验实际版本信息。

若版本横跨学习、开发或测试分区，停止将其加入画像并审查分区污染；不要静默移动已有记录。来源核验与分区调整是不同操作。

## 来源纠正

用户提供的“其他作者”“独作”等描述先记为待核验来源信息。对照实验前，用署名页或出版社记录核验，并检查是否有目标作者合著。

发现作者归属错误后：

- 在原记录加入日期、正确来源与核验依据，明确撤回的推断。
- 从负对照或作者区分度证据中排除，说明哪些计数受影响、哪些不受影响。
- 保留已生成演示及其暴露状态，不能追认为独立盲评；不自动追加到学习或最终测试集合。
- 同步修改生成该记录的本地脚本，防止重跑恢复旧错误。

## 从片段到规则

逐页视觉核验阅读顺序后保存完整句序列，记录章节、页码和引用边界。每条规则附短引文、适用条件、反例和作品数。历史参考单列，不为当代规则增加支持篇数。

原页匹配、哈希一致和引用存在只验证出处，不验证规则解释、个人专属性或生成质量。合著作品数也不等于统计独立样本量。新增规则先作开发演示；独立生成和导师匿名评价另行验证，最终测试集继续冻结。
