# Apply the reviewed style sheet

Inputs: approved style sheet; two or three learning examples from the same section; new content brief or draft; factual constraints; length requirement.

First identify immutable claims, numbers, citations, comparison directions, negations, sample scope and causal language. Write in English using supported style patterns. Preserve content. Do not import results, citations or distinctive multi-sentence wording from reference papers. Mark missing information instead of inventing it.

Return: revised draft, concise change log, claim-by-claim preservation check, unresolved issues. The check is a proposed review aid, not a guarantee. Save outputs only under local/drafts/.
